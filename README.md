# dont-make-me-think (Agent Skill)

A usability skill that operationalizes Steve Krug's *Don't Make Me Think*
(and the *Revisited* mobile chapter) for building and reviewing web and
mobile interfaces — reducing cognitive load, making pages self-evident,
designing for scanning, fixing confusing navigation, and cutting needless words.

Compatible with [vercel-labs/skills](https://github.com/vercel-labs/skills).

## Install

```bash
npx skills add <this-repo-url> --skill dont-make-me-think
```
